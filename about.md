# About MarkdownCanDo

MarkdownCanDo is a free, browser-based place to learn, write, and explore Markdown. It combines an [interactive beginner tutorial](/tutorial/), a [WYSIWYG Markdown editor](/playground/), a [syntax cheat sheet](/reference/cheatsheet/), and editable [examples](/showcase/).

## What the site is for

The project is designed to make plain-text writing approachable without hiding how Markdown works. Beginners can start with visual editing and short lessons, while experienced users can test tables, task lists, formulas, Mermaid diagrams, footnotes, and other extensions.

## How content is maintained

MarkdownCanDo is maintained by Gantrol Hwang with changes tracked in the public [GitHub repository](https://github.com/gantrol/markdown-can-do). Content aims to:

- show complete, testable examples;
- distinguish broadly supported Markdown from optional extensions;
- keep editor text in the browser rather than requiring an account;
- correct errors transparently through the repository history.

Some older translations may be updated after the primary version. If a translated page is incomplete or unclear, please report it so it can be reviewed.

MarkdownCanDo is part of the same independent project family as [AI Can Do](https://www.aicando.xyz/), which publishes practical AI articles, and [Model Chronicle](https://timeline.aicando.xyz/), a sourced timeline of model events.
