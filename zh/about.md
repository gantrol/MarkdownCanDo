# 关于 MarkdownCanDo

MarkdownCanDo 是一个免费的浏览器端 Markdown 学习与写作网站，提供<a href="/zh/tutorial/">交互入门教程</a>、<a href="/zh/playground/">所见即所得编辑器</a>、<a href="/zh/reference/cheatsheet/">语法速查表</a>和可编辑的<a href="/zh/showcase/">完整示例</a>。

## 网站目标

这个项目希望让纯文本写作更容易上手，同时不隐藏 Markdown 的工作方式。初学者可以从可视化编辑和短教程开始，有经验的用户则可以测试表格、任务列表、公式、Mermaid 图表、脚注等扩展功能。

## 内容如何维护

MarkdownCanDo 由黄健楸维护，所有修改都记录在公开的 [GitHub 仓库](https://github.com/gantrol/markdown-can-do)中。内容遵循以下原则：

- 提供可以实际运行和检查的完整示例；
- 区分通用 Markdown 语法与需要平台支持的扩展；
- 编辑器文字在浏览器内处理，不要求注册账号；
- 通过公开版本记录修正错误。

MarkdownCanDo 与 [AI能做.XYZ](https://www.aicando.xyz/) 和 [模型纪年](https://timeline.aicando.xyz/) 属于同一组独立维护项目：前者发布 AI 实测与专题文章，后者按时间和来源整理模型事件。
