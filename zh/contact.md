# 联系 MarkdownCanDo

报告问题或建议改进的可靠方式，是使用项目公开的 [GitHub Issues](https://github.com/gantrol/markdown-can-do/issues)。

## 反馈时请提供

- 出现问题的页面网址；
- 你原本期待的结果；
- 实际发生的情况；
- 必要时提供浏览器和设备信息；
- 能重现问题的最小 Markdown 示例。

如果是事实性内容修正，请链接到具体标题，并尽量提供可靠来源。

## 隐私相关请求

GitHub Issues 是公开的，请勿发布密码、私人文档、个人身份信息或其他敏感内容。网站的数据处理说明见<a href="/zh/privacy">隐私政策</a>。

你还可以阅读<a href="/zh/about">关于 MarkdownCanDo</a>和<a href="/zh/terms">使用条款</a>。
