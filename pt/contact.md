# Contato do MarkdownCanDo

A forma mais confiável de relatar um problema ou sugerir uma melhoria é pelo [rastreador público de issues no GitHub](https://github.com/gantrol/markdown-can-do/issues).

## O que incluir

- a URL da página;
- o resultado que você esperava;
- o que aconteceu de fato;
- navegador e dispositivo, quando relevante;
- um pequeno exemplo Markdown que reproduza o problema.

Para uma correção de conteúdo, indique o título afetado e forneça uma fonte confiável quando se tratar de uma afirmação factual.

## Pedidos de privacidade

Issues do GitHub são públicas. Não publique senhas, documentos privados, identificadores pessoais ou outras informações sensíveis. As práticas de dados do site estão na <a href="/pt/privacy">política de privacidade</a>.

Você também pode conhecer melhor o <a href="/pt/about">MarkdownCanDo</a> e consultar os <a href="/pt/terms">termos de uso</a>.
