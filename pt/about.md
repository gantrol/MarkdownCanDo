# Sobre o MarkdownCanDo

MarkdownCanDo é um site gratuito para aprender, escrever e explorar Markdown no navegador. Ele reúne um <a href="/pt/tutorial/">tutorial interativo</a>, um <a href="/pt/playground/">editor Markdown WYSIWYG</a>, uma <a href="/pt/reference/cheatsheet/">folha de dicas</a> e <a href="/pt/showcase/">exemplos editáveis</a>.

## Objetivo do site

O projeto busca tornar a escrita em texto simples acessível sem esconder como o Markdown funciona. Iniciantes podem começar pela edição visual e por lições curtas; usuários experientes podem testar tabelas, tarefas, fórmulas, diagramas Mermaid, notas de rodapé e outras extensões.

## Como o conteúdo é mantido

MarkdownCanDo é mantido por Gantrol Hwang, com alterações registradas no [repositório público do GitHub](https://github.com/gantrol/markdown-can-do). O conteúdo procura:

- oferecer exemplos completos e verificáveis;
- diferenciar a sintaxe amplamente aceita das extensões opcionais;
- processar o texto do editor no navegador, sem exigir uma conta;
- corrigir erros de forma transparente pelo histórico do projeto.

O MarkdownCanDo faz parte da mesma família de projetos independentes que o [AI Can Do](https://www.aicando.xyz/), dedicado a testes e artigos sobre IA, e o [Model Chronicle](https://timeline.aicando.xyz/), uma linha do tempo de eventos com fontes.
